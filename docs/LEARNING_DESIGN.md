# Learning Design

Open Guitar Practice is organized around short retrieval sessions rather than passive reference browsing. Learners may choose any activity, while the Today screen gives one low-friction recommendation and the progress system preserves continuity.

## Fretboard and Scales

- Begin with one string and natural notes, then expand the string pool and enable accidentals.
- Separate note-name recall from functional scale-degree recall.
- Teach modes by both parallel comparison (what degree changes) and relative relationship (shared parent major scale).
- Generate 3NPS shapes from the selected tonic instead of memorizing disconnected diagrams.
- Add intervallic traversal only after the scalar path is clear: seconds, thirds, fourths, cells, and reverse motion.

## Chords

- Treat major, minor, and diminished as interval formulas before asking for Roman numerals.
- Show the diatonic triad sequence for every mode, not only major and natural minor.
- Present guitar shapes as voicings of chord tones, including open, barre, CAGED, and diminished examples.
- Pair every theory page with an active recall exercise.

## Ear Training

- Establish a tonic with a cadence or scale before presenting a target. The task is functional scale-degree hearing, not isolated interval naming.
- Start with tonic and dominant, add the tonic triad, then tendency tones, the full major collection, natural minor, and modal color tones.
- Weight weak and due items more heavily; require accuracy across every target before unlocking the next level.
- Encourage singing or humming before answering, then play the degree's resolution after feedback.
- Transfer the skill across roots, registers, and timbres only after the basic function is stable.
- Develop melodic memory from two-note stepwise calls to leaps, longer major/minor phrases, and modal sequences.

## Rhythm

- Use a consistent loop: hear the whole groove, isolate layers, copy with visible support, recall without support, then build the grid.
- Introduce quarter-note pulse, backbeat, eighth-note rock, syncopation, sixteenths, double-kick, halftime, and metal vocabulary gradually.
- Score both event accuracy and timing; expose tempo, scaffolding, looping, handedness, and latency calibration.
- Use the Web Audio clock for playback scheduling so visual rendering does not determine musical timing.

## Motivation Without Noise

XP, streaks, mastery bars, and level unlocks make progress visible, but do not block free practice. The primary reward remains competence: clearer feedback, a gradually expanding note/mode pool, and exercises that connect hearing, theory, the fretboard, and physical playing.
